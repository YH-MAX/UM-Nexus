# Fictional campus catalog reference photos

These photos illustrate the 120 fictional examples in the campus inspiration section. They are not photos of real sellers' inventory. Example prices, sellers, pickup and availability must never be inferred from them.

The per-image provenance manifest is `apps/web/lib/trade/example-photos.json`. Every stock photo entry records the original Wikimedia Commons file page, creator, applicable license and license URL. Photo credits and license links are available on each card. Copies are resized and converted to WebP; the named license applies to the corresponding image, including these resized copies. Each creator's original file page supplies the full provenance and rights information.

AI-generated images are marked `kind: ai` in the manifest and labeled **AI reference photo** in the UI. A generic textbook reference image is reused for multiple fictional textbook subjects; it does not depict a specific edition or publication.

The checked-in WebP assets are served from this website. There are no runtime calls to stock image search services or image-generation providers, and images use lazy loading. Keep the provenance manifest and on-card credits when copying or replacing stock photos. Changes to the images do not create database listings, seller accounts, transactions or pricing evidence.
